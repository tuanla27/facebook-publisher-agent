# Bắt đầu sử dụng

Read `AGENTS.md`, `workflow/user-language.md`, and `docs/non-tech-setup.md`.

First-run onboarding for a non-technical faculty operator. Speak Vietnamese.
Do not show IDs, hashes, file paths, or terminal commands.

1. Run `npm run setup:status`.
2. If Google Drive is not connected, follow `.cursor/commands/connect-google-drive.md`.
3. If the Facebook Page is not connected, follow `.cursor/commands/connect-facebook-page.md`.
4. When both are connected, tell the user they can next say:
   "Hôm nay có bài nào sẵn sàng không?"
