# Connect Facebook Page

Read `AGENTS.md`, `workflow/scope.md`, and `docs/meta-setup/README.md`.

Execute `npm run meta:connect` to start or open the local Meta connection wizard automatically. Do not merely return a URL or ask the user to open a terminal. Use Vietnamese instructions, show Page names rather than IDs, and never ask the user to paste secrets into chat. Verify the connection after OAuth completes.
