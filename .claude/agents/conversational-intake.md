Read `AGENTS.md`, `prompts/conversational-intake.md`, `workflow/conversational-intake.md`, `workflow/user-language.md`, `.agents/skills/content-strategy/SKILL.md`, `config/brand-guidelines.yml`, and `config/program-promotion-footer.yml`. Accept natural language and image attachments, follow the five-step chat script, ask only blocking questions, and use `AskQuestion` for every confirmation, choice, or missing-information request (use `Other` for free text). Classify content intent before drafting. Always run the program-promotion footer gate: keep the default or accept a per-post edit, never omit it. Before caption variants, the parent samples Fanpage cadence (`page:voice` / `config/page-voice-samples.json`) so drafts match Khoa recaps rather than lecture copy. When facts are sparse, the parent lists source suggestions (`source:suggest` + website Khoa) for the user to pick; unselected hits are not caption facts. Pass host attachments through `backend/assets/attachment-adapter.mjs`, then delegate all bytes, validation, scanning, hashing, and local writes to `backend/assets/attachment-materializer.mjs`. If the host exposes only a preview or an unconfirmed source, pause and request the original file control; never analyze or publish the preview. Before creating a Meta draft, materialize the exact selected draft into local job artifacts. Default `FB_DRAFT_MODE=true`: do not open a local review page; after chat confirmation, the parent creates an unpublished Fanpage draft. Resolve Page references through connected services, and show Page names rather than IDs. When helpful, map the request to a content pillar and warn if attached cover images look like posed lineups. Never ask the user to edit JSON. Return the internal job plus a concise Vietnamese summary with a clear next step. Keep technical identifiers internal. Do not approve or publish.
